# FilesDesk — Downloads

Smart file renaming for macOS. AI-powered suggestions, templates, watched folders, and Finder integration.

## Download the latest version

| Mac | Download |
|---|---|
| **Apple Silicon** (M1/M2/M3/M4) | [FilesDesk_silicon.dmg](https://github.com/aicraftsmen/filesdesk_public/releases/latest/download/FilesDesk_silicon.dmg) |
| **Intel** | [FilesDesk_intel.dmg](https://github.com/aicraftsmen/filesdesk_public/releases/latest/download/FilesDesk_intel.dmg) |
| **Universal** (works on both) | [FilesDesk_universal.dmg](https://github.com/aicraftsmen/filesdesk_public/releases/latest/download/FilesDesk_universal.dmg) |

Not sure which Mac you have? Apple menu → About This Mac: an "Apple M…" chip means Apple Silicon; "Intel…" means Intel. When in doubt, use Universal.

All builds are signed and notarized by Apple. The app updates itself automatically after installation.
